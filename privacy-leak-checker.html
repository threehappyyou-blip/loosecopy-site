Did you leave an email or key in there?

A draft built from your real notes sometimes carries along things that were only ever meant for you — a personal email, a phone number, a key or token you pasted in for reference. Easy to miss in a wall of text you've already read three times. This scans for it before you publish, not after.

🔒 Runs entirely in your browser — nothing you paste here is sent anywhere, including to us.

contact info key, token, or card number
Found a live key or token in here? Revoke or rotate it wherever it came from, whether or not you end up posting this — pasting it into a draft is often how it got remembered in the first place. Back to the generator →

Card numbers are checked with the Luhn checksum that real card numbers satisfy, so a random 16-digit number won't trigger a false alarm.

Pattern-matching only — it catches things shaped like an email, phone number, a handful of well-known API key formats (OpenAI/Anthropic-style, GitHub, AWS, Slack, bearer tokens), a long random-looking string, or a number that passes a real card checksum. It will NOT catch a password written in plain words, a home address, or anything identifying that doesn't match one of these shapes — this is one check, not a guarantee. Example addresses like you@example.com are ignored on purpose. When in doubt, read the whole draft once more yourself before you post.
